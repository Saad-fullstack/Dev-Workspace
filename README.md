# 🚀 Dev Workspace

Dev Workspace is an all-in-one productivity dashboard built for students and developers. It helps users organize their daily work, manage notes, track learning progress, and stay focused through a clean and responsive interface.

## 🌐 Live Demo

🔗 https://dev-workspace-rho.vercel.app/

## 📂 GitHub Repository

🔗 https://github.com/Saad-fullstack/Dev-Workspace

---

## ✨ Features

### 📋 Task Manager
- Add, edit, and delete tasks
- Mark tasks as completed
- Priority badges (High, Medium, Low)
- Local Storage support
- Empty state UI

### 📝 Notes Manager
- Create, edit, and delete notes
- Local Storage support
- Empty state UI

### ⏱ Focus Timer
- Pomodoro timer
- Start, pause, and reset controls
- Custom focus session selection
- Break time settings

### 🗺 Learning Roadmap
- Create your learning roadmap
- Update progress
- Edit and delete roadmap
- Track current and next milestones

### 📊 Analytics Dashboard
- Total tasks
- Completed tasks
- Notes created
- Task completion progress
- Roadmap progress
- Productivity summary
